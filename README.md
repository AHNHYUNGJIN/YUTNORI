# 가족 윷놀이 PWA

React 18 + TypeScript + Vite 기반의 모바일 우선 전통 윷놀이 앱입니다. 순수 도메인 규칙, AI 전략, Zustand 통합 스토어, 테스트 하네스를 포함합니다.

## 게임 규칙 (정통 규칙 반영)

- **29밭 전통 윷판**: 바깥 20밭 + 지름길 8밭 + 방(중앙). 모서리·방에 **딱 멈춘 다음 차례에만** 지름길로 진입합니다.
- **던지기 예산**: 차례마다 1번. 윷·모가 나오거나 상대 말을 잡으면 1번 추가.
- **윷 판정**: 도·개·걸·윷·모 + 백도(✕ 표식 가락만 배) + 낙(2% 확률, 던지기 소모).
- **백도**: 말이 실제로 지나온 길(track)을 따라 정확히 한 칸 후진. 첫 밭에서 백도가 나오면 참먹이(출발점)로 — 다음 던지기에 바로 골인!
- **업기·잡기**: 같은 밭의 내 말은 자동으로 업혀 함께 이동, 상대 말을 잡으면 상대는 처음부터.
- **골인**: 출발점을 지나면 도착. 말 4개가 모두 도착하면 승리.
- 움직일 수 없는 차례(낙, 대기 말뿐인 백도 등)는 자동으로 넘어갑니다.

## 조작

1. **윷 던지기** 버튼으로 던지기 (남은 횟수 표시)
2. 점수판의 **대기 말** 또는 판 위의 반짝이는 말을 터치 (다시 터치하면 선택 취소)
3. **금빛 도착 칸**을 눌러 직접 이동을 확정 — 결과가 여러 개면 원하는 칸을 선택 (예상 경로 미리보기 표시)

## AI 난이도

- 쉬움: 무작위 / 보통: 잡기·전진·위험 회피 휴리스틱 / 어려움: 상대의 기대 반격(윷 확률 분포 기반)까지 계산
- `npm run simulate` — 1000판 AI 자동 대전으로 종료 보장·난이도 승률을 검증합니다.

## 실행
- `npm install`
- `npm run dev`
- `npm test` (커버리지 포함 단위 테스트)
- `npm run test:e2e` (Playwright, 모바일+데스크톱)
- `npm run lint`
